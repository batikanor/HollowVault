The signer was never in the room.

An Ethereum signing primitive whose private key was created inside SpaceComputer's Orbitport KMS and signs there. Each signature is bound to a fresh satellite-attested cosmic-randomness draw. The chain verifies offline.

Five checks. All must pass.
